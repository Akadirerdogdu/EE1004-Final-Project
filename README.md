# Fleet Maintenance Scheduler

EE1004 Object-Oriented Programming Final Project.

## JDK Version
Java 17

## Compile
In a command line, run:
javac MaintenanceScheduler.java

## Run
In a command line, run:
java MaintenanceScheduler

## OOP Concepts Used
• Abstraction
• Inheritance
• Polymorphism
• Encapsulation
